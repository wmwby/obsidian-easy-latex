# Easy LaTeX 插件国际化（i18n）设计

## Context

插件设置页面、Notice 提示等文本全部硬编码为中文，不管用户 Obsidian 设置的是什么语言。需要添加国际化支持，使其跟随 Obsidian 的 locale 自动切换语言，并提供可扩展框架方便未来新增语言。

## 方案

采用轻量 TS 翻译文件 + `t()` 函数的方式，这是 Obsidian 社区插件的主流做法。

## 文件结构

```
src/i18n/
  index.ts        # t() 函数 + locale 检测 + 语言注册
  en.ts           # 英文翻译
  zh-cn.ts        # 中文翻译
```

## Locale 检测

通过 Obsidian 内置的 `moment.locale()` 获取当前语言，回退到 `en`：

```ts
const locale = window.moment?.locale?.() ?? 'en';
```

无需用户手动配置，完全跟随 Obsidian 设置。

## 需要修改的文件

| 文件 | 改动内容 |
|------|----------|
| `src/i18n/index.ts` | 新建，导出 `t(key)` 函数 |
| `src/i18n/en.ts` | 新建，英文翻译 |
| `src/i18n/zh-cn.ts` | 新建，中文翻译 |
| `src/settings.ts` | 所有硬编码中文替换为 `t('xxx')` |
| `src/main.ts` | Notice 文本替换为 `t('xxx')` |
| `src/types.ts` | 默认系统提示词改为从 i18n 获取 |

## 新增语言

只需：
1. 在 `src/i18n/` 下新建 `<locale>.ts`，导出相同 key 的翻译
2. 在 `index.ts` 中注册

## Verification

1. Obsidian 设为中文 → 设置页面显示中文
2. Obsidian 设为英文 → 设置页面显示英文
3. Notice 提示跟随语言切换
4. 插件功能（补全、AI 生成）不受影响
